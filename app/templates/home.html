Turn any web page into a clean table

Web Scraper lets you pick the data you need straight from your browser. Tell it which HTML elements to look for, and get the results as a table you can download as CSV.

Start scraping Try it on a demo site

How it works

  1. Set the page

    Paste the page URL and choose how many elements you want to collect.

  2. Describe the data

    For each element pick the tag, its class or id, and whether it contains nested items.

  3. Get the results

    Review everything in a table and download it as a CSV file.
